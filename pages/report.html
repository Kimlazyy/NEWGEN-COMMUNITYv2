รายละเอียดการแจ้งใบ

  • GOPRO / OVERLAY ต้องมีเสียงของผู้ถูกกระทำผิดและผู้แจ้งที่ชัดเจน เปิด ID ให้เห็นชัดเจนในเหตุการณ์ ถ้าหากตัววาร์ปเปิดให้เห็น PL ด้วย Overlay หรือ คลิปที่นำมาแจ้งต้องมีความยาว 15 วินาทีขึ้นไป และ ต้องมีเหตุการณ์ที่ชัดเจน หากส่งคลิปมาเป็นแบบปิดเสียงไว้ หรือมีความยาวไม่ถึง 15 วินาที ทีมงานจะถือว่าไม่สามารถใช้เป็นหลักฐานได้ทุกกรณี เพื่อป้องกันการปกปิดการกระทำผิดของตนเอง [ ยกเว้นกรณีสงสัยตัวแปลก , โปร ไม่ต้องมีเสียงก็ได้ ] และกฎทุกข้อขึ้นอยู่กับดุลยพินิจของแอดมิน
  • หมายเหตุ : ถ้าหากคลิปที่ใช้แจ้งเสียงไม่ชัดเจนเหตุการณ์ในคลิปไม่ชัดเจน [ ภาพกระตุกหรือแตก ] ไม่สามารถใช้เป็นหลักฐานได้ทุกกรณี
  • หมายเหตุ : ไม่รับรูปในการแจ้งใบทุกกรณี ยกเว้นกรณีเเจ้งบัฟทวิตหรือโพสต์ในทวิตเท่านั้น
  • หมายเหตุ : แอดมินจะไม่แนบหลักฐานการแจ้งใบทุกกรณี
  • หลักฐานการแจ้งใบ จะสามารถแจ้งได้ไม่เกิน 12 ชั่วโมง นับจากเวลาที่เกิดเหตุ หากเกินเวลา 12 ชั่วโมงจะถือว่าเป็น โมฆะ ทันที
  • ผู้เล่นที่จะเล่นการพนันไม่ว่าจะ โต๊ะบาร์ [ Baccarat ] หรือ โป๊กเกอร์ [ Poker ] หรือ Warzone ผู้เล่นจะต้องมี Overlay หรือ ID ของผู้เล่นที่ทำการบิดเงิน หรือ ต้องเคย Give เงินให้ เท่านั้น ทาง Server ถึงจะทำเรื่องแบนหรือลงโทษให้ได้ [ Overlay ต้องได้ยินเสียงชัดเจน ]
  • หมายเหตุ : หากมีการเดิมพันนอกโต๊ะ POKER ไม่รับแจ้งทุกกรณี
  • หมายเหตุ : ห้ามโยกเงินบริเวณโต๊ะ POKERโทษ : 🟨 ใบเหลือง
  • ไม่สามารถนำเอาคลิปวิดีโอหน้าสตรีมของบุคลคนอื่นมาแจ้งใบเด็ดขาด ต้องเป็นเจ้าของบุคคลนั้นๆถึงจะสามารถแจ้งเองได้ รวมถึงคลิปไฮไลท์ที่ลงตามแพตฟอร์มต่างๆทุกช่องทาง
  • กรณีที่ไม่มีหลักฐานดังกล่าว ขออนุญาติไม่รับเรื่องใดๆทั้งสิ้นและไม่รับแจ้งเรื่องจากปากปล่าว
  • หากต้องการจะแย้งใบ จะต้องมีคลิปที่สมบูรณ์มาแย้ง ไม่รับยืนยันปากเปล่าหรือพยาน ภายใน 24 ชม. เท่านั้น
  • หากมีการแจ้งใบเท็จ เช่น การนำคลิปที่ตัดมาแล้วทำให้ฝั่งตัวเองถูก หากคู่กรณีมีหลักฐานมาแย้งโทษ : 🟨 ใบเหลือง
  • สตอรี่สามารถ แจ้งใบได้หลังจากที่จบสตอรี่แล้วเท่านั้น ไม่สามารถแจ้งใบระหว่างที่มีสตอรี่ได้
  • หมายเหตุ : รวบรวมหลักฐานเปิด Ticket มาแค่ คนเดียว ระยะเวลาส่งหลักฐาน ภายใน 24 ชม. หลังจบสตอรี่เท่
  • เพื่อรักษาสิทธิ์ของตัวเองทุกครั้งที่เล่น รบกวนอัด OVERLAY ไว้ทุกครั้ง

    • หมายเหตุ : หากไม่มี Overlay ของตัวเองที่แย้ง ทีมงานจะตัดสินตามหลักฐานมุมมองบุคคลโดนที่แจ้งหลักฐานมาเท่านั้น และดุลยพินิจของแอดมิน

    รายละเอียดการแจ้งโปรแกรมช่วยเล่น

  • กรณีโปรเเกรมช่วยเล่น overlay ในการเเจ้งเรื่อง ขั้นต่ำ 30 วินาที เเละจะต้องเปิด Fps , pl เเละ ping ให้ชัดเจน
  • [ ถ้าหากเปิดไม่ครบไม่รับเช็คทุกกรณี และปัดตกทุกกรณี ] [ ถ้าคลิปไหนชัดเจนทางประเทศจะแบนเลยทันทีไม่เช็คใดๆทั้งสิ้น ย้ำว่า ทางประเทศไม่สนับสนุนการเล่นโปรแกรมช่วยเล่นทุกชนิด ]
  • สำหรับ ใครที่ โดน Ghostx แบน แล้วเด้งออกให้กด Ticket มาทันทีภายในเวลาที่โดนห้ามเกิน 2 นาที และให้กด Overlay ย้อนหลังทันทีขั้นต่ำต้อง 5 นาทีเท่านั้น !! หากไม่มีหรือมีแค่ 2-4 นาทีจะยึดตาม Log ที่ขึ้น เท่านั้นจะอ้างว่าบริสุทธิ์ไม่ได้หากไม่มี Overlay ให้ทางแอดมินดู
  • ถ้าหากมีการเเจ้งเตือน Token ban ออกประเทศ ผู้เล่นจะต้องรีบเปิด ticket เพื่อเเสดงความบริสุทธิ์
  • [ หากผู้เล่นไม่มาติดต่อ ภายใน 20 นาที จะถือว่ามีโทษโปรเเกรมช่วยเล่นตามกฏประเทศทันที ] โทษ : 🟥 ใบเเดงถาวร
  • ถ้ามีการเเจ้งเช็คผู้เล่นเเล้วพบว่าเป็นคอมที่เล่นจากร้านเกม เเล้วมีประวัติการปิดเครื่องหรือออกเกมในตอนที่มีการเรียกเช็คc
  • หมายเหตุ : ต้องมีคลิปหลักฐานว่าจอฟ้าหรือไฟดับเท่านั้น
  • ถ้าหากมีการลบข้อมูลหรือลงวินโดว์ในช่วงเวลาที่มีการเรียกเช็คจะมีโทษโทษ : 🟥 ใบเเดง
  • หากมียศ DISCORD ในร้านขายโปรโทษ : 🟨 ใบเหลือง
  • หากประกาศเรียกตัวแล้วไม่มาติดต่อภายใน 2 ชั่วโมง จะทำการระงับไวริส หากเกิน 4 ชั่วโมงโทษ : 🟥 ใบเเดงถาวร
  • หากแอดมินเรียกเช็คเครื่องแล้ว ถ้าคอมค้างถ่ายรูปมาให้ชัดเจน
  • หากผู้เล่นคนไหนอัด OVL ไม่ได้จริงๆให้ติดต่อสภาหรือแอดมินก่อนเล่นสตอรี่
  • ห้ามพูดถึงโปรแกรมช่วยเล่นโทษ : 🟨 ใบเหลือง

    • ระยะเวลาของหลักฐานที่ใช้แจ้ง

  • ระยะเวลาในการส่งหลักฐานเพื่อใช้แจ้งใบ จะต้องส่งหลักฐานมาแจ้งภายใน 12 ชม. เท่านั้นหากครบแล้วทางทีมงานจะถือหลักฐานชิ้นนั้นไม่สามารถใช้ในการแจ้งเรื่องได้ทุกกรณี
  • [ หลักฐานในการแจ้งจำเป็นต้องเห็นวันที่ และ เวลาที่ชัดเจน ]
