🏠 คำแนะนำการแจ้งใบ

รายละเอียดการแจ้งใบ

  • หลักฐานที่ใช้แจ้งใบ
    GOPRO / OVERLAY ต้องมีเสียงของผู้ถูกกระทำผิดและผู้แจ้งที่ชัดเจน เปิด ID ให้เห็นชัดเจนในเหตุการณ์
    หากตัววาร์ป ต้องเปิดให้เห็น PL ด้วย
    คลิปที่ใช้แจ้งต้องมีความยาวอย่างน้อย 15 วินาที และต้องเห็นเหตุการณ์อย่างชัดเจน
    หากปิดเสียง หรือคลิปสั้นกว่า 15 วินาที จะไม่สามารถใช้เป็นหลักฐานได้ทุกกรณี เพื่อป้องกันการปกปิดการกระทำผิดของตนเอง

    📌 ยกเว้นกรณีสงสัยตัวแปลกหรือโปรแกรมช่วยเล่น ไม่จำเป็นต้องมีเสียง และกฎทุกข้อขึ้นอยู่กับดุลยพินิจของแอดมิน
  • หมายเหตุ : หากคลิปที่ใช้แจ้ง เสียงไม่ชัดเจน หรือภาพแตก ภาพกระตุก จะไม่สามารถใช้เป็นหลักฐานได้ทุกกรณี
  • หมายเหตุ : ไม่รับรูปภาพในการแจ้งใบทุกกรณี ยกเว้นการแจ้งบัฟทวิตหรือโพสต์ใน Twitter
  • หมายเหตุ : แอดมินจะไม่แนบหลักฐานการแจ้งใบทุกกรณี
  • ระยะเวลาการแจ้งใบ
    หลักฐานสามารถใช้แจ้งได้ไม่เกิน 12 ชั่วโมง นับจากเวลาที่เกิดเหตุ หากเกินเวลาจะถือว่าเป็นโมฆะทันที
  • การพนัน Baccarat / Poker / Warzone
    ผู้เล่นต้องมี Overlay หรือมีหลักฐาน Give เงินให้ผู้เล่นคนนั้น จึงจะสามารถดำเนินการลงโทษได้

    Overlay ต้องได้ยินเสียงชัดเจน
  • หมายเหตุ : หากเป็นการเดิมพันนอกโต๊ะ Poker จะไม่รับแจ้งทุกกรณี
  • ห้ามโยกเงินบริเวณโต๊ะ Poker

    🟨 โทษ : ใบเหลือง
  • ห้ามนำคลิปจากสตรีมของผู้อื่นมาแจ้งใบ
    ต้องเป็นเจ้าของคลิปเท่านั้น รวมถึงคลิป Highlight หรือคลิปจากทุกแพลตฟอร์ม
  • หากไม่มีหลักฐานดังกล่าว ทีมงานขอสงวนสิทธิ์ไม่รับเรื่องทุกกรณี และไม่รับแจ้งจากคำพูดเพียงอย่างเดียว
  • การแย้งใบ
    ต้องมีคลิปหลักฐานที่สมบูรณ์ ไม่รับคำยืนยันปากเปล่าหรือพยาน ภายใน 24 ชั่วโมงเท่านั้น
  • ห้ามแจ้งใบเท็จ
    เช่น ตัดต่อคลิปให้ฝ่ายตัวเองได้เปรียบ หากคู่กรณีมีหลักฐานแย้งได้

    🟨 โทษ : ใบเหลือง
  • การแจ้งใบหลังจบสตอรี่
    สามารถแจ้งได้ หลังจากจบสตอรี่เท่านั้น ไม่สามารถแจ้งระหว่างที่กำลังเล่นสตอรี่ได้
  • หมายเหตุ : ให้รวบรวมหลักฐานเปิด Ticket เพียงคนเดียว และส่งหลักฐานภายใน 24 ชั่วโมง หลังจบสตอรี่
  • เพื่อรักษาสิทธิ์ของตนเอง ขอความร่วมมืออัด Overlay ทุกครั้งที่เล่น

📌 หมายเหตุ : หากไม่มี Overlay ของตัวเองสำหรับแย้ง ทีมงานจะพิจารณาตามหลักฐานของผู้แจ้ง และดุลยพินิจของแอดมินเท่านั้น

รายละเอียดการแจ้งโปรแกรมช่วยเล่น

    • การแจ้งโปรแกรมช่วยเล่น
      Overlay ที่ใช้แจ้งต้องมีความยาวขั้นต่ำ 30 วินาที
      และต้องเปิด FPS / PL / Ping ให้เห็นอย่างชัดเจน
    • 📌 หมายเหตุ : หากเปิดข้อมูลไม่ครบ จะไม่รับเช็คและปัดตกทุกกรณี
      หากหลักฐานชัดเจนเพียงพอ ทางประเทศสามารถแบนได้ทันที โดยไม่ต้องเรียกเช็คเพิ่มเติม
      ทางประเทศไม่สนับสนุนการใช้โปรแกรมช่วยเล่นทุกชนิด
    • กรณีโดน GhostX แบน
      หากถูกเตะออกจากประเทศ ให้เปิด Ticket ภายใน 2 นาที
      และส่ง Overlay ย้อนหลัง อย่างน้อย 5 นาที
      หากมีเพียง 2–4 นาที หรือไม่มี Overlay จะยึดตาม Log ของระบบ และไม่สามารถอ้างความบริสุทธิ์ได้
    • Token Ban
      หากมีการแจ้งเตือน Token Ban ผู้เล่นต้องรีบเปิด Ticket เพื่อแสดงความบริสุทธิ์

      🟥 หากไม่มาติดต่อภายใน 20 นาที จะถือว่ามีความผิดตามกฎโปรแกรมช่วยเล่น (ใบแดงถาวร)
    • กรณีเรียกเช็คผู้เล่นจากร้านเกม
      หากตรวจพบว่าผู้เล่นใช้คอมร้านเกม และมีประวัติการปิดเครื่อง หรือออกเกม ระหว่างถูกเรียกเช็ค
    • หมายเหตุ : ต้องมีหลักฐานว่าจอฟ้า หรือไฟดับเท่านั้น
    • ห้ามลบข้อมูลหรือลง Windows
      ในช่วงเวลาที่กำลังถูกเรียกเช็ค

      🟥 โทษ : ใบแดง
    • หากมียศ Discord ในร้านขายโปรแกรมช่วยเล่น

      🟨 โทษ : ใบเหลือง
    • กรณีประกาศเรียกตัว
      หากไม่มาติดต่อภายใน 2 ชั่วโมง จะทำการระงับไวท์ลิสต์
      หากเกิน 4 ชั่วโมง

      🟥 โทษ : ใบแดงถาวร
    • หากแอดมินเรียกเช็คเครื่อง แล้วคอมค้าง ให้ถ่ายรูปหน้าจอ ส่งให้เห็นอย่างชัดเจน
    • หากผู้เล่นอัด Overlay ไม่ได้จริง ให้ติดต่อสภา หรือแอดมินก่อนเล่นสตอรี่
    • ห้ามพูดถึงโปรแกรมช่วยเล่น

      🟨 โทษ : ใบเหลือง

    ระยะเวลาของหลักฐานที่ใช้แจ้ง

    • ระยะเวลาการส่งหลักฐาน
      ต้องส่งหลักฐานภายใน 12 ชั่วโมง หลังเกิดเหตุ หากเกินกำหนด จะไม่สามารถใช้หลักฐานดังกล่าว ในการแจ้งเรื่องได้ทุกกรณี
    • 📌 หลักฐานที่ใช้แจ้ง จำเป็นต้องเห็นวันที่ และเวลาที่ชัดเจน
